# GhostMod

A client-side utility mod that simplifies the generation and management of ghost items, blocks and more


## Installation
1. Download and run the [Fabric installer](https://fabricmc.net/use).
2. Download [Fabric API](https://modrinth.com/mod/fabric-api)
   and move it to the mods folder (`.minecraft/mods`).
3. Download the latest version of ghostmod from the [releases page](https://github.com/Guitarjoecode/ghostmod/releases)
   and move it to the mods folder (`.minecraft/mods`).

## Usage

`/ghostblock set 56 45 123 minecraft:stone` Places a ghost stone block

`/ghostblock fill ~ ~ ~ ~2 ~2 ~2 minecraft:sand` Places a square of ghost blocks at your current position

`/ghostdestroy ~ ~-1 ~` Destroys the block under you / creates a server-side ghost block

`/ghostitem minecraft:command_block 5` Gives you 5 ghost command blocks

`/ghostentity minecraft:warden` Summons a ghost warden at your position

`/ghostentity clear` Clears all ghost entities

`/ghostinfo` Gives you useful information about your player and the Minecraft world

`/ghostenable ghostblocks` Enable to use ghost blocks 

`/ghostparticle minecraft:angry_villager ~ ~ ~` Spawns a ghost particle at your position
